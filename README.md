# Фильтрация артефактов ЭМГ

Проект сравнивает способы удаления общего артефакта из многоканальной ЭМГ. 

## Структура проекта

```text
data/raw        исходные FIF-файлы, не изменяются
data/interim    переиспользуемые промежуточные результаты методов
data/processed  финальные канонические очищенные данные
outputs/figures сгенерированные рисунки
outputs/qc      разметка, маски и диагностические файлы
outputs/tables  численные сводки
```

Ожидаемый входной файл по умолчанию:

```text
data/raw/raw_artifacts_emg.fif
```

Большие данные и сгенерированные результаты намеренно не отслеживаются в Git.
